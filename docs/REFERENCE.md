## 기상청 단기예보 발표 시각

하루 8회 발표되며, 각 발표 시각 **+10분** 이후부터 조회됩니다.

```
0200  0500  0800  1100  1400  1700  2000  2300
```

02시 이전에 조회하면 **전날 2300** 회차를 써야 합니다.
`src/sources/weather.py` 의 `latest_base()` 가 이 계산을 합니다.

### 예보 코드값

| 코드 | 의미 | 비고 |
|---|---|---|
| `TMP` | 1시간 기온 (℃) | |
| `TMN` / `TMX` | 일 최저/최고 (℃) | **하루 한 번만** 응답에 등장 |
| `POP` | 강수확률 (%) | |

## 에어코리아 등급

`*Grade` 값은 **1 좋음 / 2 보통 / 3 나쁨 / 4 매우나쁨** 입니다.

농도 기준 (㎍/㎥):

| | 좋음 | 보통 | 나쁨 | 매우나쁨 |
|---|---|---|---|---|
| PM10 | ~30 | ~80 | ~150 | 150~ |
| PM2.5 | ~15 | ~35 | ~75 | 75~ |

등급이 결측일 때는 `src/sources/air.py` 의 `_grade()` 가 농도로 직접 환산합니다.

`dataTime` 이 `"2026-09-12 24:00"` 처럼 **24시 표기**로 오는 경우가 있어
`datetime.strptime` 이 실패할 수 있습니다. 현재는 문자열 그대로만 표시합니다.

## 실거래가 응답 파싱 주의

- `dealAmount` 는 `"    350,000"` — 앞 공백 + 콤마 + 단위 **만원**
- `dealYear/Month/Day` 는 제로패딩이 없습니다 (`8`, `14`)
- `cdealType == "O"` 는 **해제된 거래** → 집계 제외
- `excluUseAr` 은 전용면적 ㎡, 평 환산은 ÷3.305785
- 1회 호출 = **1개 시군구 × 1개월**
